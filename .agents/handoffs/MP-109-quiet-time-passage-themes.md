# MP-109 본문 주제 기반 QT 질문 세트 인수인계

## 구현 내용

- 하나의 QT 본문에 기본 주제와 복수 보조 주제를 가중치, 근거 구절과 함께 연결했습니다.
- 리더가 초점 주제와 진행 방식(균형, 묵상, 나눔, 실천, 새신자)을 선택해 질문을 미리 볼 수 있습니다.
- 모임 생성 시 주제, 질문, 실천·기도 안내, 버전을 세션에 스냅샷으로 저장합니다.
- 참여자의 답변은 이후 본문 템플릿이 바뀌어도 모임 생성 당시 질문을 참조합니다.
- 기존 본문에는 Flyway V35가 일반 주제를 보강하며, 큐레이션 본문에는 복수 주제를 적재합니다.

## 검증

- `./gradlew test`: 전체 성공
- 빈 PostgreSQL 17 + pgvector에서 Flyway V1~V35 적용 성공
- Flyway 적용 후 Hibernate 스키마 검증과 애플리케이션 기동 성공
- 주제 정렬, 질문 차이, 세션 스냅샷, 허용되지 않은 주제 거부 통합 테스트 추가

## 운영 정책

- 한 본문에는 기본 주제를 최대 하나만 허용합니다.
- 질문은 요청 시 AI로 생성하지 않아 비용과 응답 변동을 제거했습니다.
- 향후 전 성경 자동 분류는 이 주제 사전을 사용하되, 신뢰도와 신학 검수 상태를 추가하고 승인된 결과만 게시해야 합니다.
- 생성된 세션의 질문은 수정하지 않습니다. 질문 개선은 새 버전으로 배포하고 새 모임부터 적용합니다.

## 후속 작업

- 전 성경 구절 범위 분류 배치와 관리자 검수 큐
- 주제 사전 및 질문 버전 관리 화면
- 실제 모임 데이터를 이용한 질문 품질 지표와 피드백 분석
