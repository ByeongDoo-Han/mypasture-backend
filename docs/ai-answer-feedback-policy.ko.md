# AI 목자 답변 피드백 정책

## 목적

사용자 피드백은 모델을 즉시 학습시키는 데이터가 아닙니다. 답변 품질 추세, 잘못된 성경 구절 신고,
검색·프롬프트 개선 우선순위를 판단하는 운영 데이터로 사용합니다.

## 사용자 정책

- 한 사용자는 답변 한 건에 최종 평가 한 건을 가지며 다시 평가하면 기존 값을 갱신합니다.
- `도움됨`은 사유 없이 저장하고, `아쉬움`은 1~3개의 정해진 사유를 선택합니다.
- 자유 의견은 선택 사항이며 300자로 제한합니다.
- 피드백 제출은 AI 일일 사용 횟수를 차감하지 않습니다.
- `아쉬움` 답변은 원래 질문이 일치할 때 한 번 무료로 다시 받을 수 있습니다.
- 개선 생성이 실패하면 사용 횟수를 차감하지 않고 다시 시도할 수 있습니다.
- 동시에 여러 번 누르면 한 요청만 처리하고, 5분 이상 멈춘 작업만 장애 재시도로 간주합니다.

## 개인정보와 보안

- 질문 원문은 사용량 로그에 저장하지 않고 사용자별 비밀키 기반 HMAC만 저장합니다. 다시 보기용 질문·최종 답변·기도문은 별도 AI 기록에 암호화해 원본 질문 생성일 기준 365일(연결된 개선 답변 포함) 또는 이용자 삭제·탈퇴 시점까지 보관합니다.
- 자유 의견은 AI 대화와 다른 용도 분리 키로 AES-GCM 암호화합니다.
- 자유 의견은 prompt injection을 막기 위해 AI 재생성 프롬프트에 전달하지 않습니다.
- 정해진 사유 코드만 서버의 검토된 개선 지침으로 변환합니다.
- 관리자 집계 API는 질문, 답변, 자유 의견을 노출하지 않습니다.
- 사용량 로그 삭제 시 관련 피드백도 함께 삭제해 1년 보유 정책을 따릅니다.

## 비용과 품질

- 개선 답변도 RAG 검색, 성경 인용 검증, 생성·평가 모델 검사를 동일하게 거칩니다.
- 이전 근거가 관련 없거나 잘못됐다는 사유면 다른 후보 구절을 우선 검색합니다.
- 개선 생성은 무료지만 토큰, embedding, 평가 비용을 별도 로그로 기록합니다.
- 잘못되거나 존재하지 않는 구절 신고는 관리자 우선 검수 목록에 포함합니다.
