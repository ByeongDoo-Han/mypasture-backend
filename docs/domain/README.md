# 도메인 정책

[문서 전체 색인](../README.md) · 계정, 콘텐츠, 보상, 알림 및 QT에서 적용할 규칙을 모았습니다. 정책 문서의 기술만으로 현재 코드·배포 적용 여부를 판단하지 말고 관련 구현과 함께 확인합니다.

새 규칙이나 정책 변경을 기록할 때는 `상태`(사용자 확정·코드 확인·제안·미결·폐기), `근거`(이슈·코드·운영 확인과 날짜), `현재 구현`, `남은 검증`을 적습니다. 사용자 결정과 코드에서 관찰한 동작을 같은 상태로 표시하지 않습니다. 기존 문서에 상태가 없다면 확인 전까지 확정이나 구현 완료로 추정하지 않습니다. 폐기된 규칙은 대체 문서나 이슈로 연결합니다.
