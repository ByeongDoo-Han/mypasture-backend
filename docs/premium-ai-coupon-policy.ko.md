# 프리미엄 AI 목자 체험 쿠폰 정책

## 기본 정책

- 쿠폰은 사용자의 실제 구독 등급을 변경하지 않고 `PREMIUM_AI_TRIAL` 권한을 일정 기간 지급한다.
- 공유 코드는 여러 사용자가 전체 한도까지 등록하고, 개별 코드는 코드마다 한 명만 등록한다.
- 캠페인에는 등록 시작·종료 시각, 전체 등록 한도, 체험 기간, AI 일일 한도를 반드시 둔다.
- 기본 MVP 체험은 등록 시점부터 7일, 하루 30회이며 운영자가 캠페인별로 조정할 수 있다.
- `eligibilityKey`가 같은 캠페인은 계정당 평생 한 번만 등록할 수 있다. 새 코드를 발급해도 같은 체험을 반복할 수 없다.
- 체험이 끝나면 기존 대화 기록은 조회 가능하지만 새 프리미엄 후속 대화는 무료 정책으로 차단한다.

## 보안과 부정 사용 방지

- 쿠폰 원문은 DB와 로그에 저장하지 않는다. 정규화된 코드를 서버 비밀값으로 HMAC-SHA256 처리해 조회한다.
- 등록 API는 인증 사용자 단위 Redis rate limit을 적용한다.
- 사용자, 캠페인, 코드 행 잠금과 DB unique constraint를 함께 사용해 동시 중복 지급을 막는다.
- 사용자별 체험 제한은 마케팅 수신 동의와 연결하지 않는다.
- 고가치 쿠폰은 공유 코드보다 개별 코드를 사용하고 유출 시 캠페인을 즉시 비활성화한다.

## 운영 절차

1. 운영자는 등록 기간과 예상 대상 수를 기준으로 캠페인을 생성한다.
2. 생성 응답의 개별 코드는 원문을 다시 조회할 수 없으므로 승인된 채널에 한 번만 안전하게 보관한다.
3. 사용률과 실패율을 관찰하고 오발급 또는 유출 시 캠페인을 비활성화한다.
4. 캠페인 중지는 신규 등록만 막으며 이미 지급된 권한은 유지한다. 강제 회수는 별도의 사유·감사 기능으로 구현한다.

## 운영 환경변수

- `COUPON_CODE_PEPPER`: 32바이트 이상의 무작위 서버 비밀값. 모바일이나 관리자 브라우저에 노출하지 않는다.
- `COUPON_REDEEM_RATE_LIMIT_PER_WINDOW`: 기본 60초당 사용자 8회.
