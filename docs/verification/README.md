# 검증

[문서 전체 색인](../README.md) · 재현 가능한 검사 방법과 당시의 결과·점검 기록을 모았습니다. 날짜가 있는 결과는 해당 환경과 버전의 측정값이며 현재 운영 성능이나 심사 상태를 나타내지 않습니다.

기능 변경의 검사 범위는 [AGENTS.md](../../AGENTS.md)의 위험도 기준과 [CI 선택 규칙](../../.github/scripts/select_tests.py)을 따릅니다. 명령·대상 커밋·환경·실제 통과/실패 수와 미실행 사유는 해당 이슈·PR 또는 [작업 기록](../tasks/README.md)에 남깁니다. 이 색인은 과거 결과를 현재 통과로 대체하지 않습니다.
